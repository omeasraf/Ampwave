How exports work & Apple requirements

Local files: place this HTML next to your screenshots. Opening HTML directly uses the browser’s local-file protection. “Choose screenshot folder…” gives this page permission to read the matching images for this session; nothing is uploaded. Clicking Export before choosing a folder opens the picker and resumes the export after loading. “Choose image files…” and drag-and-drop are alternatives. Reloading the page requires selecting the folder again.

No file picker when using a local server: from this folder run python3 -m http.server 8000 --bind 127.0.0.1, then open http://127.0.0.1:8000/ and select this HTML. The screenshot files load from the same local origin and can be exported directly.

Everything means all 16 screenshots: iPhone includes home, library, playlists, nowPlaying, lyrics, settings, search, and artist. iPad includes Home, Library, Now_Playing, Lyrics, and Settings. Watch includes Home, Playing, and Songs. The composite snapshot image and PDF are not app screenshots, so they are not exported. Missing images block the requested batch instead of silently producing an incomplete ZIP.

Fixed renderer: v4 draws text, frames, and fully decoded screenshots directly onto the final canvas. It does not render HTML inside SVG. Screenshot pixels are checked before encoding, and the actual file dimensions are checked after encoding. Use “Preview export” on any card to inspect the actual output image before downloading.

Artwork: designed iPhone and iPad segments include their text and device frame. Screenshots are contained at their original aspect ratio, never stretched. Each complete segment is fitted into its target canvas; padding can be added. Watch exports contain the screenshot only, without a decorative frame or marketing text. “Match source” sets iPhone/iPad canvas orientation from each source image; it does not rotate the app UI.

Apple dimensions: the iPhone default is 1284 × 2778 for the 6.5-inch upload slot. That slot accepts 1284 × 2778 or 1242 × 2688 in portrait, and 2778 × 1284 or 2688 × 1242 in landscape. The iPhone upload-slot selector filters the size choices: a size accepted in another slot is not necessarily accepted in the slot you are uploading to. Actual encoded dimensions are checked before any download. The iPad default is 2064 × 2752 (swapped for landscape). Watch Auto preserves a common accepted source size; otherwise it uses 422 × 514 for the entire Watch set. Use an explicit Watch size to keep the same dimensions across localizations. Resizing cannot add detail or substitute for a real device-specific capture.

Upload the images, not the ZIP: unzip first. Files are grouped by device and pixel size, with a JSON manifest and a README. Apple accepts 1–10 screenshots per set in PNG or JPEG, without alpha channels or transparency. The limit is checked per device, not across the whole archive. PNG output is 8-bit RGB with an sRGB tag and no alpha channel; JPEG is rendered onto an opaque sRGB canvas at 98% quality.

Browser & fonts: use a current desktop browser. PNG uses CompressionStream when available, with a standards-based uncompressed fallback. No JavaScript libraries are downloaded. Canvas exports use the fonts already loaded by the page. Original DM fonts load from Google Fonts at runtime; use System fonts for offline use. Font files are not bundled. A font-loading failure uses built-in Arial/Georgia and reports a warning.

Dimensions and no-alpha rules checked on September 25, 2026 against Apple’s screenshot specifications ↗. Correct pixel dimensions do not guarantee App Review approval. Check your final artwork before uploading.
